# Product roadmap

## Implemented prototype — current

- [x] Set up the Next.js App Router, TypeScript, Tailwind CSS, and shadcn/ui.
- [x] Add shared navigation and dedicated Overview, Forecasting, Inventory,
      Traceability, Intelligence, Monitoring, Analytics, and About routes.
- [x] Build a responsive overview using synthetic demand, inventory, shipment,
      batch, and anomaly evidence.
- [x] Add deterministic forecast and anomaly calculations, local demo
      workflows, and typed shared records.
- [x] Add route/query/error states, cross-module search, deployment/portfolio
      documentation, and repeatable browser checks.

## Next — validate the product hypotheses

- [ ] Validate a specific planner/operator job through discovery; no personas
      or research findings are claimed in this prototype.
- [ ] Confirm legal access, data quality, identifiers, event timestamps, and
      retention requirements with source owners.
- [ ] Evaluate one narrow deterministic signal against expert-adjudicated,
      chronologically held-out data before any operational pilot.
- [ ] Agree on workflow outcome, alert burden, and safety/privacy guardrails
      before adding telemetry or shared persistence.

## Later — only if validated and approved

- [ ] Agree on data contracts and connect an authorized operational data source.
- [ ] Define model evaluation, explanations, and human review before adding AI.
- [ ] Threat-model identity, permissions, audit requirements, and retention.
- [ ] Evaluate a shared backend, carrier/sensor feeds, or ledger only when
      requirements justify the capability and an authorized owner is available.
- [ ] Deploy only after owner approval, then verify routes and public data
      disclosures on the actual hosted application.

No live integrations, user research, experiments, or public deployment are
part of this synthetic portfolio prototype.
