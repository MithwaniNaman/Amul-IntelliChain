# Screenshot capture checklist

Capture real pages from a running build; do not mock data or represent
synthetic values as live operations. Use a clean browser profile and keep the
visible simulated-data disclaimer in frame.

Suggested files:

1. `overview-desktop.png` — Overview at 1440 × 1000, showing KPI cards,
   demand chart, regional inventory, and compact intelligence summary.
2. `forecasting-desktop.png` — Forecasting at 1440 × 1000 with a selected
   product/location and forecast controls visible.
3. `inventory-detail-desktop.png` — Inventory at 1440 × 1000 with one
   synthetic record detail Sheet open; avoid showing personal browser data.
4. `intelligence-evidence-desktop.png` — Intelligence at 1440 × 1000 with
   `SHP-88416` filtered and its evidence detail open.
5. `traceability-batch-mobile.png` — batch detail at 390 × 844 showing the
   local verification disclosure and lifecycle.
6. `about-disclosure.png` — About page at 1440 × 1000 showing independence
   and integration limitations.

application and re-check them for accurate labels and public-safe content.
